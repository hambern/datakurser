# Uppgift 5: API-projekt

### Syfte
Denna uppgift syftar till att ge dig praktisk erfarenhet av att använda och integrera ett publikt API i en webbapplikation. Du kommer att utforska hur externa datakällor kan användas för att skapa dynamiska och interaktiva webbapplikationer. Genom att använda PHP för att hämta och bearbeta data, och Bootstrap för att designa gränssnittet, kommer du att få en djupare förståelse för både backend- och frontend-utveckling.

### Mål
Efter att ha slutfört denna uppgift ska du kunna:
- Utföra HTTP-förfrågningar mot ett externt API och hämta data med hjälp av PHP.
- Bearbeta och presentera data i en strukturerad och användarvänlig layout.
- Använda Bootstrap för att skapa ett responsivt och estetiskt tilltalande gränssnitt.
- Presentera ditt projekt muntligt och förklara hur API:et integrerats och används.

### Beskrivning
Du ska skapa en webbapplikation som hämtar data från ett externt API som du väljer utifrån dina intressen. Applikationen ska presentera denna data på ett tydligt och användarvänligt sätt. Du har frihet att välja vilket API du vill, men det kan vara allt från sociala medier, offentliga data, väderinformation, eller något annat som intresserar dig.

#### Krav för projektet:
1. **API-val och integration:**
   - Välj ett API som du tycker är intressant och som tillhandahåller den typ av data du vill arbeta med.
   - Använd PHP för att hämta och bearbeta data från API:et.
   - Tänk på att vissa API:er kräver en API-nyckel för åtkomst. Se till att hantera API-nycklar på ett säkert sätt.

2. **Gränssnittsdesign:**
   - Använd Bootstrap för att skapa en stilren och responsiv design.
   - Presentera data på ett tydligt och strukturerat sätt. Använd t.ex. tabeller, kort, listor eller andra Bootstrap-komponenter.
   - Inkludera användarinteraktioner, som att filtrera eller söka i datan, om API:et tillåter det.

3. **Presentera projektet:**
   - Förbered en kort presentation av ditt projekt. Beskriv vilket API du har valt, hur du har integrerat det, och hur du har använt PHP och Bootstrap för att skapa din applikation.
   - Visa upp applikationen och förklara hur den fungerar.

### Ramverk och tekniker
- **PHP:** Använd PHP för att hämta och bearbeta data från API:et.
- **Bootstrap:** Använd Bootstrap för att designa gränssnittet och skapa en responsiv layout.
- **JavaScript (valfritt):** Du kan också använda JavaScript för att förbättra användarupplevelsen med dynamiska funktioner och interaktivitet.

### Tips och tricks

- **Färgscheman:** Använd verktyg som [Coolors](https://coolors.co/) för att hitta snygga färgscheman till din applikation.
- **Bootstrap-komponenter:** Utforska [Bootstrap-dokumentationen](https://getbootstrap.com/docs/5.0/getting-started/introduction/) för att hitta komponenter och layoutalternativ som kan passa ditt projekt.
- **API-integration:** Läs noggrant igenom dokumentationen för det API du valt för att förstå dess möjligheter och begränsningar.

### Resurser att studera
För att förbereda dig inför denna uppgift rekommenderas att du studerar följande resurser:
- [PHP och API-förfrågningar](https://www.w3schools.com/php/php_json.asp) för att lära dig hur du kan hämta och bearbeta API-data med PHP.
- [Bootstrap](https://getbootstrap.com/) för att designa ett responsivt och användarvänligt gränssnitt.
- [Public APIs](https://github.com/public-apis/public-apis) för att hitta fler intressanta API:er att utforska.
