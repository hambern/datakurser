# Extrauppgift - Chatbot

I denna uppgift ska du forka skapa och uppdatera en egen chatbot. Läs följande delar innan du sätter igång:

- https://www.w3schools.com/git/git_remote_fork.asp?remote=gitlab

## Instruktioner

1. Forka detta repository <https://gitlab.com/hambern/quickbot> och installera din version av det på din studentserver
2. Utgå ifrån branchen `vue` och kontrollera så att allt funkar som det ska
3. Gör chatroboten databasbaserad genom att lägga till följande tabeller i din databas:
    - `qb_intents`
    - `qb_utterances`
    - `qb_answers`
